Forge ist installiert

Öffne Forge aus dem Ordner „Programme“. Falls der ESP32-Core wegen fehlendem Netz nicht geladen werden konnte, holt Forge ihn beim ersten Start mit einer Fortschrittsanzeige nach.

Für die Code-Vorschläge nutzt Forge clangd aus den Xcode Command Line Tools (xcode-select --install). Ohne sie gilt die eingebaute Vorschlagsliste.
